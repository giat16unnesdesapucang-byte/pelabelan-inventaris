BAB I: PENGENALAN SISTEM

Sistem Informasi Inventarisasi Aset Desa Pucang adalah platform digital yang dirancang khusus untuk menatausahakan, melacak, dan mengamankan seluruh Barang Milik Desa (BMD) secara transparan, terpadu, dan akuntabel.

🌟 Tiga Pilar Utama Sistem:
  1. Desktop Admin Panel (Windows App): Pusat kendali pengurus barang balai desa untuk pendataan master aset, cetak stiker QR massal, serta penerbitan laporan resmi Microsoft Excel (.xlsx) standar KIB.
  2. Mobile Scanner PWA (Smartphone): Aplikasi pemindai kamera lapangan untuk petugas desa guna melayani transaksi pinjam/kembali barang warga secara instan.
  3. Cloud Real-Time Database (Supabase): Database cloud terenkripsi yang menyinkronkan data antar laptop dan HP secara otomatis seketika.
BAB II: PANDUAN APLIKASI DESKTOP ADMIN

2.1 Menjalankan Aplikasi Desktop

1 Buka File Explorer laptop kantor desa, masuk ke folder: desktop-admin/bin/Release/net9.0-windows/win-x64/publish/.
2 Klik 2x pada file DesktopAdmin.exe. Aplikasi akan terbuka dan otomatis terhubung ke cloud.

2.2 Menambah Data Aset (Fitur Smart Auto-SKU)

Sistem dilengkapi generator kode otomatis yang menyusun kode aset sesuai standar:

Format Baku: PCG - [KODE_KATEGORI] - [TAHUN] - [NO_URUT] (Contoh: PCG-ELK-2026-001)
  1. Masuk ke menu Data Aset di bilah kiri $\rightarrow$ Klik tombol hijau "+ Tambah Aset".
  2. Ketik Nama Aset (contoh: Laptop Lenovo ThinkPad Sekdes).
  3. Pilih Kategori Aset (Elektronik, Mebel, Kendaraan, Peralatan, Bangunan).
  4. Pilih Sumber Dana (Dana Desa/DDS, ADD, PADes, Bankeu Prov/Kab, Hibah).
  5. Tentukan Tanggal Perolehan (Tahun pembelian).
  6. Klik tombol "⚡ Buat Kode Otomatis" untuk mengisi kode SKU secara otomatis anti-kembar.
  7. Isi Lokasi Simpan dan Nilai Aset (Harga Perolehan Rp).
  8. (Opsional) Klik "Pilih Foto" untuk melampirkan foto fisik asli barang.
  9. Klik tombol hijau "Simpan Aset".

2.3 Mencetak Stiker Label QR Code

1 Pada tabel Data Aset, pilih barang yang ingin dicetak (bisa pilih satu atau blok banyak barang dengan tombol Ctrl).
2 Klik tombol biru "Cetak Batch QR".
3 Jendela pratinjau cetak akan muncul menampilkan stiker QR berlogo resmi Desa Pucang.
4 Klik "🖨️ Cetak ke Printer" untuk mencetak ke kertas stiker label.

2.4 Ekspor Laporan Resmi Microsoft Excel (.xlsx)

  • Buku Inventarisasi Aset (KIB): Di halaman Data Aset, klik "📊 Export Laporan Excel (.xlsx)". Dokumen memuat KOP Resmi Desa, Kartu Ringkasan KPI Eksekutif, Akuntansi Rupiah, Formula SUM, dan Kolom Pengesahan Tanda Tangan Kepala Desa.
  • Laporan Peminjaman Bulanan / SPJ: Di halaman Sirkulasi Peminjaman, klik "📊 Export Laporan Peminjaman (.xlsx)" $\rightarrow$ pilih periode Bulan Ini (Default) atau Rentang Tanggal Kustom $\rightarrow$ Laporan resmi periode terpilih siap diunduh.

2.5 Mengatur PIN Petugas Mobile

Klik menu "⚙️ PIN Petugas Mobile" di sidebar bawah $\rightarrow$ masukkan PIN Baru (4–8 angka) $\rightarrow$ klik "Simpan PIN Baru".

BAB III: PANDUAN APLIKASI MOBILE SCANNER (PWA)

3.1 Aktivasi Perangkat & Pasang Aplikasi ke Layar HP

1 Buka browser di smartphone (Google Chrome / Safari) $\rightarrow$ buka link Vercel resmi desa.
2 Pada layar "Aktivasi Perangkat Petugas", masukkan PIN Keamanan (Default: 123456).
3 Begitu berhasil, muncul banner hijau "📲 Pasang Aplikasi Aset Desa" $\rightarrow$ Klik "Pasang".
4 Ikon aplikasi kini terpasang di layar utama HP dan bebas PIN untuk penggunaan seterusnya!

3.2 Memindai QR Code & Alur Peminjaman Warga

  1. Ketuk tombol pemindai bulat hijau [ ⛶ ] di menu bawah. Kamera belakang otomatis aktif.
  2. (Opsional) Jika HP memiliki banyak lensa, ketuk "🔄 Ganti Lensa Kamera" untuk berpindah kamera.
  3. Arahkan ke stiker QR barang $\rightarrow$ Halaman detail barang langsung terbuka.
  4. Ketuk tombol "📦 Pinjamkan Aset Ini" $\rightarrow$ Masukkan Nama Peminjam, NIK KTP, No. WhatsApp, dan Tanggal Batas Kembali $\rightarrow$ Klik "Konfirmasi Peminjaman".
  5. Saat warga mengembalikan barang, scan kembali QR barang tersebut $\rightarrow$ ketuk "↩️ Proses Pengembalian". Status barang seketika kembali Tersedia!
BAB IV: TROUBLESHOOTING & SOLUSI CEPAT
Kendala Penyebab Solusi
Kamera HP tidak menyala saat scan Izin akses kamera di browser belum diizinkan Buka Pengaturan Browser HP $\rightarrow$ Izin Situs $\rightarrow$ Kamera $\rightarrow$ Pilih "Izinkan".
Lupa PIN Petugas Lapangan PIN pernah diubah Buka Desktop Admin di laptop desa $\rightarrow$ menu "⚙️ PIN Petugas Mobile" untuk melihat/mereset PIN.
Aplikasi HP ingin dikunci ulang Smartphone dipindahtangankan Di Beranda HP, ketuk badge hijau "🛡️ Terotorisasi" di pojok kanan atas $\rightarrow$ pilih "OK / Kunci".
